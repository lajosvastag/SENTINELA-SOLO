# Contribuindo

Sugestões e melhorias para o SENTINELA-SOLO são bem-vindas.

1. Abra uma issue descrevendo o problema ou a proposta.
2. Crie uma branch com nome curto e descritivo.
3. Mantenha as alterações compatíveis com ESP32/Arduino.
4. Atualize a documentação quando alterar pinos, formato JSON ou calibração.
5. Teste com `pio run` e descreva o hardware usado no pull request.

Por favor, não inclua senhas de Wi-Fi, chaves ou dados de propriedade no repositório.
